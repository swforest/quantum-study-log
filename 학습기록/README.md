# 일일 학습 기록

이 폴더에는 실제로 진행한 양자컴퓨팅 학습 내용을 날짜별로 기록합니다.

일자별 수업 문서는 학습 자료이고, 이 폴더의 문서는 그 자료를 사용해 실제로 무엇을 이해하고 실습했는지 남기는 학습 일지입니다.

## 파일 이름

다음 형식을 사용합니다.

```text
YYYY-MM-DD_주차_요일.md
```

예:

- `2026-09-02_01주차_수요일.md`
- `2026-09-11_02주차_금요일.md`

계획된 날짜와 실제 학습 날짜가 다르면 파일 이름에는 실제 학습 날짜를 사용하고, 문서 안에 사용한 수업 문서의 원래 날짜를 따로 기록합니다.

## 기록 원칙

- 실제로 학습한 내용만 작성합니다.
- 정답보다 처음 생각한 답과 수정 과정을 남깁니다.
- 코드를 실행하기 전에 예상한 결과를 기록합니다.
- 실행 결과를 붙이는 데 그치지 않고 결과가 의미하는 바를 설명합니다.
- 틀린 문제와 오개념은 삭제하지 않고 교정 과정을 함께 남깁니다.
- 새로 알게 된 연관 용어를 짧게 정의합니다.
- 다음 복습 날짜와 다시 풀 문제를 구체적으로 정합니다.
- 토큰, 비밀번호, 계정 정보, 로컬 전용 경로는 기록하지 않습니다.

## 학습 종료 시 갱신할 파일

1. 오늘 날짜의 일일 학습 기록
2. 루트의 [학습_진행표.md](../학습_진행표.md)
3. 학습 중 오류가 발견된 경우에만 해당 수업 문서

## 작성 순서

1. [일일 학습 기록 템플릿](일일_학습기록_템플릿.md)을 복사합니다.
2. 실제 학습 날짜에 맞게 파일 이름을 변경합니다.
3. 시작 전 회상부터 학습 중에 바로 기록합니다.
4. 종료 시 완료 기준과 다음 복습일을 확정합니다.
5. 공개 전 점검표를 확인합니다.

## Git 기록

하루 학습은 가능한 한 하나의 커밋으로 남깁니다.

권장 커밋 메시지:

```text
study: YYYY-MM-DD 학습 주제
```

예:

```text
study: 2026-09-02 큐비트와 상태벡터
```

커밋과 push는 변경 내용을 확인한 뒤 사용자가 명시적으로 요청한 경우에만 수행합니다.
