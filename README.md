# 양자컴퓨팅·Qiskit 8주 복구 과정

이 저장소는 예전에 양자컴퓨팅을 공부했지만 기억이 흐릿해진 학습자가, **개념을 다시 이해하고 최신 Qiskit 2.x로 직접 구현할 수 있는 상태**로 돌아가기 위한 8주 과정입니다. 단순히 강의 노트를 읽는 방식이 아니라, 기억 인출·손계산·코드 예측·직접 구현·오답 설명의 순서로 학습합니다.

과정은 2026년 9월 2일부터 10월 23일까지이며, 첫 주는 수요일부터 금요일까지 3일, 이후에는 월요일부터 금요일까지 진행합니다. 하루 기준 학습 시간은 2시간이고 총 38회, 약 76시간입니다. 적힌 날짜에 학습하지 못해도 날짜를 건너뛰지 말고 같은 주차와 요일의 문서를 다음 학습일에 사용합니다.

## 이 과정의 최종 목표

8주를 마치면 다음을 할 수 있어야 합니다.

1. 큐비트, 중첩, 상대위상, 측정, 얽힘을 수식과 말로 설명합니다.
2. 상태벡터, 연산자, 밀도행렬, 기대값을 손으로 계산하고 Qiskit으로 확인합니다.
3. `QuantumCircuit`으로 회로를 작성하고 측정 결과의 비트 순서를 올바르게 해석합니다.
4. 회로를 `BackendV2`의 제약에 맞게 트랜스파일하고 결과를 비교합니다.
5. `StatevectorSampler`, `StatevectorEstimator`, `SamplerV2`, `EstimatorV2`의 역할과 입출력 구조를 구분합니다.
6. QUBO 문제를 Ising Hamiltonian으로 옮기고 작은 QAOA 최적화 루프를 구성합니다.
7. 구형 Qiskit 예제를 볼 때 개념과 폐기된 API를 분리하여 현대식 코드로 바꿉니다.
8. 답을 외우는 대신 회로의 상태 변화와 예상 결과를 먼저 추론합니다.

## 사용 자료

- 기존 한국어 자료: [Qiskit-Dev-Cert-lectures](https://github.com/QuantumComputingKorea/Qiskit-Dev-Cert-lectures)
- 최신 학습 기준: [IBM Quantum Documentation](https://quantum.cloud.ibm.com/docs)
- 현재 Qiskit SDK 기초 API: [Qiskit API 문서](https://quantum.cloud.ibm.com/docs/en/api/qiskit)

기존 한국어 저장소는 Qiskit `0.29.1`을 기준으로 하므로 개념 설명과 문제 소재만 선별하여 사용합니다. `execute`, `BasicAer`, `IBMQ`, `qiskit.tools`, V1 `Sampler`·`Estimator`를 그대로 따라 하지 않습니다. 자세한 변환 기준은 [자료_API_현대화_가이드.md](자료_API_현대화_가이드.md)를 참고합니다.

| 주차 | 핵심 질문 | 결과물 |

| 7주 | 고전 최적화 문제를 QAOA로 어떻게 옮기는가? | 로컬 QAOA 기준 구현 |
| 8주 | 배운 내용을 하나의 재현 가능한 프로젝트로 만들 수 있는가? | 최종 프로젝트와 개인 복습 지도 |

## 하루 2시간 운영법

일자별 문서에는 더 세밀한 시간이 적혀 있으며 기본 구조는 다음과 같습니다.

| 구간 | 시간 | 목적 |
|---|---:|---|
| 회상 | 15분 | 책을 보지 않고 전 시간 핵심을 말하거나 적습니다. |
| 개념 A | 30분 | 정의와 직관을 연결하고 짧은 손계산을 합니다. |
| 점검·휴식 | 10분 | 틀린 가정을 확인하고 잠시 쉽니다. |
| 개념 B | 30분 | 첫 개념을 회로·알고리즘 문맥으로 확장합니다. |
| 단계별 실습 | 25분 | 실행 전에 결과를 예측한 뒤 코드를 작성합니다. |
| 정리 | 10분 | 오늘의 핵심과 미해결 질문을 기록합니다. |

첫 주는 기억 복구가 목표이므로 수학·개념 80%, 코드 20%로 운영합니다. 이후에는 개념과 코드 비율을 점차 50:50으로 맞춥니다.

## Codex와 학습을 시작하는 방법

다음과 같이 말하면 됩니다.

```text
1주 수요일 학습하자
2주 금요일 학습하자
지난 시간 15분 복습부터 하자
오늘은 60분만 진행하자
3주 목요일 문제만 다시 풀자
5주 수요일에서 틀린 부분을 복습하자
```

주차와 요일이 주어지면 Codex는 해당 문서를 열고 다음 순서로 진행합니다.

1. 오늘의 목표와 예상 시간을 짧게 알립니다.
2. 첫 회상 질문을 **한 개만** 냅니다.
3. 학습자가 답하기 전에는 정답이나 다음 단계를 공개하지 않습니다.
4. 막히면 작은 힌트, 방향 힌트, 계산 힌트 순으로 제공합니다.
5. 답을 받은 뒤 맞은 부분과 수정할 부분을 구분합니다.
6. 수식과 코드 실행 전에 결과를 먼저 예측하게 합니다.
7. 이해 확인 질문에 답한 뒤에만 다음 단계로 갑니다.
8. 종료할 때 [학습_진행표.md](학습_진행표.md)에 기록할 요약을 제안합니다.

## 공개 학습 기록 운영

이 과정은 커리큘럼뿐 아니라 실제로 공부한 과정도 공개 Git 저장소에 남기는 것을 목표로 합니다.

학습 자료와 실제 학습 기록은 다음처럼 구분합니다.

- 주차별·일자별 문서: 공부할 내용을 제공하는 수업 자료
- [학습_진행표.md](학습_진행표.md): 전체 진도, 점수, 취약 개념, 복습 예정일
- [학습기록](학습기록/README.md): 실제로 답한 내용, 손계산, 코드 결과, 실수와 교정 과정

매일 수업이 끝나면 [일일 학습 기록 템플릿](학습기록/일일_학습기록_템플릿.md)을 복사해 실제 학습 내용을 작성합니다.

파일 이름은 `학습기록/YYYY-MM-DD_주차_요일.md` 형식을 사용합니다. 계획된 날짜보다 늦게 공부했다면 파일 이름에는 실제 학습 날짜를 쓰고 문서 안에 원래 수업 날짜를 함께 기록합니다.

공개 저장소에는 이해한 결과만 정리하지 않고 다음 내용도 남깁니다.

1. 자료를 보기 전에 했던 첫 답
2. 틀린 이유와 교정 과정
3. 코드 실행 전 예상
4. 실제 실행 결과와 해석
5. 새로 확인한 연관 용어
6. 다음 복습 날짜

IBM Quantum token, API key, 비밀번호, 인증 파일, 로컬 전용 설정은 공개 저장소에 포함하지 않습니다. 커밋과 push 전에는 변경 파일과 민감정보 포함 여부를 확인합니다.

## 학습자의 답변 원칙

- 모르면 `모르겠어`라고 말해도 됩니다. 기억을 숨기면 진단이 어려워집니다.
- 계산 결과뿐 아니라 그렇게 생각한 이유를 한 문장이라도 말합니다.
- 코드가 실행될 것이라는 사실보다 어떤 상태와 분포가 나올지를 먼저 말합니다.
- 틀린 답은 실패가 아니라 이후 반복 간격을 정하는 데이터로 사용합니다.
- 정답을 읽고 이해한 느낌과, 자료 없이 재현할 수 있는 능력을 구분합니다.

하루 수업은 단순히 문서를 끝까지 읽었다고 완료되지 않습니다. 다음 네 항목 중 세 항목 이상을 만족하면 완료로 표시합니다.

주간 완료 기준은 금요일 문서의 종합 문제 70% 이상과, 그 주의 핵심 결과물 완성입니다. 기준을 넘지 못해도 다음 주로 갈 수 있지만 다음 월요일 회상 구간에 취약 개념을 다시 넣습니다.

## 권장 개발 환경

실제 설치는 2주차 첫 수업에서 현재 환경을 확인한 뒤 진행합니다. 문서 예시는 다음 계열을 전제로 합니다.

```text
Python 3.11 또는 3.12
Qiskit 2.x
qiskit-aer
qiskit-ibm-runtime
JupyterLab 또는 VS Code Notebook
```

버전을 무조건 최신으로 올리기보다 수업 시작 시 설치된 버전을 기록하고, 공식 문서의 해당 버전 API를 확인합니다. IBM Quantum 계정 토큰이나 실제 QPU 사용은 사용자가 명시적으로 원할 때만 진행합니다. 기본 과정은 로컬 시뮬레이터와 가짜 백엔드로 완수할 수 있습니다.

## 표기 규칙

- 계산기저: $|0\rangle$, $|1\rangle$
- 일반 1큐비트 상태: $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$
- 정규화: $|\alpha|^2+|\beta|^2=1$
- 켤레전치: $A^\dagger$
- 텐서곱: $\otimes$
- 기대값: $\langle A\rangle=\langle\psi|A|\psi\rangle$
- 확률과 확률진폭을 구분하며, 진폭에는 복소수와 위상이 포함될 수 있습니다.
