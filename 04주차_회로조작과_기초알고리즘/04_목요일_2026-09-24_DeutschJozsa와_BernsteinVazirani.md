# 4주차 목요일 - Deutsch-Jozsa와 Bernstein-Vazirani

## 공통 전제

두 알고리즘은 oracle query model에서 quantum interference가 전역적 성질이나 숨은 문자열을 드러내는 예입니다. 실제 계산 비용을 말할 때 oracle 구현 비용과 문제 promise를 생략하지 않습니다.

## Deutsch-Jozsa 문제

함수 $f:\{0,1\}^n\to\{0,1\}$가 다음 둘 중 하나라는 promise가 있습니다.

- constant: 모든 입력에서 같은 값
- balanced: 입력 절반은 0, 절반은 1

목표는 어느 종류인지 판별하는 것입니다.

표준 bit oracle은

$$U_f|x,y\rangle=|x,y\oplus f(x)\rangle$$

입니다. ancilla를 $|-\rangle$로 준비하면 phase kickback으로

$$U_f|x\rangle|-\rangle=(-1)^{f(x)}|x\rangle|-\rangle$$

가 됩니다.

입력 register에 H를 다시 적용했을 때 `0...0` 진폭은

$$
\frac1{2^n}\sum_x(-1)^{f(x)}.
$$

constant면 절댓값 1, balanced면 0입니다.

## 구현 골격

```python
from qiskit import QuantumCircuit

def deutsch_jozsa(oracle: QuantumCircuit, num_inputs: int) -> QuantumCircuit:
    circuit = QuantumCircuit(num_inputs + 1, num_inputs)
    ancilla = num_inputs

    circuit.x(ancilla)
    circuit.h(range(num_inputs + 1))
    circuit.compose(oracle, inplace=True)
    circuit.h(range(num_inputs))
    circuit.measure(range(num_inputs), range(num_inputs))
    return circuit
```

oracle의 qubit ordering과 host mapping이 같다는 가정을 검사합니다.

## Bernstein-Vazirani 문제

숨은 bitstring $s$에 대해

$$f_s(x)=s\cdot x\pmod2$$

인 oracle이 주어집니다. 한 quantum query 후 간섭으로 $s$를 얻습니다.

각 $s_i=1$인 입력 qubit에서 ancilla로 CX를 연결하는 oracle을 만들 수 있습니다.

```python
def bv_oracle(secret: str) -> QuantumCircuit:
    n = len(secret)
    oracle = QuantumCircuit(n + 1, name=f"BV({secret})")
    ancilla = n

    for qubit, bit in enumerate(reversed(secret)):
        if bit == "1":
            oracle.cx(qubit, ancilla)
    return oracle
```

`reversed(secret)`는 Qiskit bit order와 사람이 쓰는 문자열을 맞추기 위한 선택입니다. 작은 secret `001`, `100`으로 검증합니다.

## 비교

| 항목 | Deutsch-Jozsa | Bernstein-Vazirani |
|---|---|---|
| 목표 | constant/balanced 판정 | 숨은 선형 bitstring 찾기 |
| promise | 함수 종류 제한 | 함수가 선형 dot product |
| 핵심 | 상쇄 여부 | 각 bit phase pattern |
| 출력 | all-zero 여부 | secret string |

## 과제

1. constant 0, constant 1 oracle을 각각 만듭니다.
2. parity balanced oracle을 만듭니다.
3. secret `10110` BV 결과를 비트 순서까지 예측합니다.
4. oracle 내부 gate 수를 무시하고 query 수만 비교할 때의 한계를 설명합니다.

- Python, Qiskit, 선택 패키지 버전을 출력합니다.

- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
