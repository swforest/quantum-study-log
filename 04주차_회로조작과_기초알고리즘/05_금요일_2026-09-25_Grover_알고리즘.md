# 4주차 금요일 - Grover 알고리즘

## 목표

- phase oracle과 diffuser의 역할을 기하학적으로 설명합니다.
- 2큐비트 단일 marked state 검색을 구현합니다.
- iteration 수와 over-rotation을 설명합니다.
- 성공 확률을 statevector와 shots로 검증합니다.

## 문제

$N=2^n$개 항목 중 $M$개의 marked item을 찾습니다. oracle은 marked basis state의 위상을 반전합니다.

$$
O|x\rangle=
\begin{cases}
-|x\rangle,&x\text{ marked}\\
|x\rangle,&\text{otherwise}
\end{cases}
$$

초기 균등중첩은

$$|s\rangle=\frac1{\sqrt N}\sum_x|x\rangle.$$

diffuser는

$$D=2|s\rangle\langle s|-I$$

이며 평균에 대한 반사로 설명할 수 있습니다. oracle 반사와 diffuser 반사를 반복하면 상태가 marked subspace 쪽으로 회전합니다.

## 2큐비트 예: marked `11`

`11` phase oracle은 CZ로 구현할 수 있습니다.

```python
from qiskit import QuantumCircuit

def oracle_11() -> QuantumCircuit:
    oracle = QuantumCircuit(2, name="mark_11")
    oracle.cz(0, 1)
    return oracle
```

2큐비트 diffuser:

```python
def diffuser_2() -> QuantumCircuit:
    diffuser = QuantumCircuit(2, name="diffuser")
    diffuser.h([0, 1])
    diffuser.x([0, 1])
    diffuser.cz(0, 1)
    diffuser.x([0, 1])
    diffuser.h([0, 1])
    return diffuser
```

전체 회로:

```python
grover = QuantumCircuit(2)
grover.h([0, 1])
grover.compose(oracle_11(), inplace=True)
grover.compose(diffuser_2(), inplace=True)
```

$N=4$, $M=1$에서는 한 iteration으로 marked state를 이상적으로 확률 1로 증폭합니다.

## 다른 marked state

`00`, `01`, `10`을 mark하려면 oracle 전후에 X를 사용하여 target bitstring을 `11`로 mapping합니다. Qiskit 문자열 순서를 작은 상태로 검증합니다.

## iteration 수

대략

$$
r\approx\left\lfloor\frac\pi}{4}\sqrt{\frac NM}\right\rfloor
$$

번이지만 작은 문제와 여러 marked states에서는 정확한 각도를 고려합니다. 너무 많이 반복하면 marked state를 지나쳐 성공 확률이 다시 낮아집니다.

## 검증

```python
from qiskit.quantum_info import Statevector

state = Statevector.from_instruction(grover)
print(state.probabilities_dict())
```

측정 회로를 복사해 Sampler로 샷 결과도 확인합니다. statevector 정확 확률과 finite-shot count를 구분합니다.

## 과제

1. 네 bitstring 각각의 oracle을 생성하는 함수를 만듭니다.
2. oracle 적용 직후 확률은 변하지 않지만 phase가 바뀌는 것을 출력합니다.
3. diffuser 이후 marked amplitude가 증가하는 과정을 배열로 기록합니다.
4. Grover iteration을 0, 1, 2회 적용해 over-rotation을 관찰합니다.
5. $M>1$일 때 iteration 수가 줄어드는 이유를 기하학적으로 설명합니다.

오늘 가장 가능성 높은 실패는 다음과 같습니다. bit-flip oracle과 phase oracle을 혼동하거나 diffuser의 H-X-다중제어위상-X-H 순서를 바꾸면 진폭 증폭이 일어나지 않습니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
