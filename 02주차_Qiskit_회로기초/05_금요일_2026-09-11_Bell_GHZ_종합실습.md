- 전역위상·비트 순서·유한 샷 오차를 고려한 테스트를 작성합니다.

## 준비 단계

답을 보지 않고 다음을 적습니다.

$$
|\Phi^\pm\rangle=\frac{|00\rangle\pm|11\rangle}{\sqrt2},
$$

$$
|\Psi^\pm\rangle=\frac{|01\rangle\pm|10\rangle}{\sqrt2}.
$$

GHZ 상태:

$$
|GHZ_3\rangle=\frac{|000\rangle+|111\rangle}{\sqrt2}.
$$

## 1단계: 기본 Bell 회로

```python
from qiskit import QuantumCircuit

def make_phi_plus() -> QuantumCircuit:
    circuit = QuantumCircuit(2, name="phi_plus")
    circuit.h(0)
    circuit.cx(0, 1)
    return circuit
```

함수는 측정 없는 상태 준비 회로를 반환합니다. 호출자가 상태 분석 또는 샷 측정을 선택할 수 있게 합니다.

## 2단계: 네 Bell 상태

$|\Phi^+\rangle$에서 local Pauli를 적용해 다른 Bell 상태를 만듭니다. 어느 qubit에 X 또는 Z를 적용할지 먼저 손으로 유도합니다.

```python
def make_bell(label: str) -> QuantumCircuit:
    circuit = make_phi_plus()

    if label == "phi_plus":
        pass
    elif label == "phi_minus":
        circuit.z(0)
    elif label == "psi_plus":
        circuit.x(1)
    elif label == "psi_minus":
        circuit.x(1)
        circuit.z(0)
    else:
        raise ValueError(f"Unknown Bell label: {label}")

    circuit.name = label
    return circuit
```

gate 순서에 따라 전역위상이 달라질 수 있으므로 상태 동등성은 `equiv`로 확인합니다.

## 3단계: 기대 상태로 검증

```python
import numpy as np
from qiskit.quantum_info import Statevector

expected = {
    "phi_plus": Statevector([1, 0, 0, 1] / np.sqrt(2)),
    "phi_minus": Statevector([1, 0, 0, -1] / np.sqrt(2)),
    "psi_plus": Statevector([0, 1, 1, 0] / np.sqrt(2)),
    "psi_minus": Statevector([0, 1, -1, 0] / np.sqrt(2)),
}

for label, target in expected.items():
    actual = Statevector.from_instruction(make_bell(label))
    assert actual.equiv(target), label
```

실패하면 즉시 답을 바꾸지 말고 다음을 확인합니다.

1. 기대 statevector의 basis order
2. X·Z를 적용한 qubit
3. 전역위상인지 상대위상인지
4. `equiv`가 아니라 배열 직접 비교를 사용했는지

## 4단계: GHZ

```python
def make_ghz(num_qubits: int) -> QuantumCircuit:
    if num_qubits < 2:
        raise ValueError("GHZ requires at least two qubits")

    circuit = QuantumCircuit(num_qubits, name=f"ghz_{num_qubits}")
    circuit.h(0)
    for target in range(1, num_qubits):
        circuit.cx(0, target)
    return circuit
```

star 형태와 chain 형태를 비교합니다.

```python
def make_ghz_chain(num_qubits: int) -> QuantumCircuit:
    circuit = QuantumCircuit(num_qubits)
    circuit.h(0)
    for control in range(num_qubits - 1):
        circuit.cx(control, control + 1)
    return circuit
```

이상적 논리 상태는 같지만 실제 backend에서는 coupling map과 error에 따라 비용이 달라질 수 있습니다. 이 차이는 5주차에서 분석합니다.

## 5단계: 샷 결과

```python
from qiskit.primitives import StatevectorSampler

measured = make_ghz(3)
measured.measure_all()

sampler = StatevectorSampler(default_shots=2000, seed=31)
result = sampler.run([measured]).result()
counts = result[0].data.meas.get_counts()
print(counts)
```

허용되는 key는 `000`, `111`입니다. 두 count가 정확히 같을 필요는 없지만 다른 key가 나오면 이상적 상태 준비나 측정 구조를 점검합니다.

## 2. 핵심 유도와 손계산

### 수학·논리 전개

Phi-plus와 Phi-minus는 각각 (00+11)/sqrt(2), (00-11)/sqrt(2)입니다. 두 상태의 ZZ 기대값은 모두 plus 1이지만 XX 기대값은 각각 plus 1과 minus 1이므로 상관축을 바꾸면 상대위상을 구분할 수 있습니다.

3. 단계마다 보존되어야 하는 정규화, 차원, type, shape, mapping을 확인합니다.

4. 마지막 식이나 객체가 오늘 중심 질문에 어떤 답을 주는지 한 문장으로 연결합니다.

5. 부호, 순서, 인덱스 가운데 하나를 바꾸었을 때 결과가 어떻게 달라지는지 반례를 만듭니다.

### 손으로 따라가는 예제

Phi-plus 준비 회로 뒤에 CX와 H를 역순으로 적용하면 00으로 돌아옵니다. Phi-minus에 같은 역회로를 적용하면 위상 정보가 첫 큐비트의 1로 변환되어 다른 basis 결과가 나옵니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. 00과 11만 나온다는 사실만 보고 상태를 Phi-plus로 단정하면 상대위상이 다른 Phi-minus나 고전적 혼합상태를 구별하지 못합니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
