# 2주차 - 최신 Qiskit 회로 기초

## 주간 목표

1주차의 수학적 상태 변화를 최신 Qiskit 회로로 옮깁니다. 목표는 메서드 이름을 외우는 것이 아니라 `초기 상태 → 게이트 → 측정 → 결과 해석`의 각 층을 구분하는 것입니다.

이번 주가 끝나면 빈 노트북에서 Bell·GHZ 회로를 만들고, 상태벡터와 샷 결과를 서로 다른 방법으로 검증할 수 있어야 합니다.

## 일정

| 요일 | 주제 | 핵심 결과물 |
|---|---|---|
| 월 | 환경·버전·QuantumCircuit 구조 | 재현 가능한 환경 기록과 첫 회로 |
| 화 | 단일 큐비트 게이트 | 게이트별 상태 변화 표 |
| 수 | 다중 큐비트 게이트 | CX·CZ·SWAP 비교 회로 |
| 목 | 측정·레지스터·비트 순서 | 비대칭 회로 bitstring 해석표 |
| 금 | Bell·GHZ 종합 실습 | 테스트가 포함된 회로 노트북 |

## 주간 완료 기준

- [ ] wildcard import 없이 필요한 namespace를 명시한다.
- [ ] 회로를 실행하기 전 statevector 또는 count를 예측한다.
- [ ] `Statevector`와 `StatevectorSampler`의 목적을 구분한다.
- [ ] 회로 그림의 위→아래 큐비트와 count 문자열의 좌→우 비트를 구분한다.
- [ ] Bell·GHZ 회로를 빈 화면에서 작성한다.
- [ ] 상태벡터의 전역위상을 고려해 동등성을 검사한다.
