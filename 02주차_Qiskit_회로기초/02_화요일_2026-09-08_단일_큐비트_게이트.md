## 핵심 개념

단일 큐비트 순수 상태는 전역위상을 제외하면 Bloch sphere의 두 각으로 쓸 수 있습니다.

$$
|\psi\rangle=
\cos\frac\theta2|0\rangle
+e^{i\phi}\sin\frac\theta2|1\rangle.
$$

$\theta$는 북극 $|0\rangle$에서 내려오는 polar angle, $\phi$는 상대위상과 관련된 azimuth angle입니다. 전역위상은 sphere 좌표에 나타나지 않습니다.

### Pauli gate

| Gate | 행렬 효과 | Bloch 관점 |
|---|---|---|
| X | $|0\rangle\leftrightarrow|1\rangle$ | x축 $\pi$ 회전 |
| Y | bit flip + 위상 | y축 $\pi$ 회전 |
| Z | $|1\rangle$ 성분 부호 반전 | z축 $\pi$ 회전 |

### 위상 gate

$$
P(\lambda)=\begin{bmatrix}1&0\\0&e^{i\lambda}\end{bmatrix}.
$$

S는 $P(\pi/2)$, T는 $P(\pi/4)$입니다. 계산기저 상태의 직접 확률은 바꾸지 않지만 상대위상을 바꿉니다.

### 회전 gate

$$R_x(\theta)=e^{-i\theta X/2},\quad
R_y(\theta)=e^{-i\theta Y/2},\quad
R_z(\theta)=e^{-i\theta Z/2}.$$

예를 들어

$$
R_y(\theta)|0\rangle
=\cos\frac\theta2|0\rangle
+\sin\frac\theta2|1\rangle.
$$

따라서 $R_y(\pi/2)|0\rangle=|+\rangle$이고 $R_y(\pi)|0\rangle=|1\rangle$입니다. 부호와 전역위상까지 정확히 비교할 때는 행렬을 사용합니다.

## 예측 후 코드

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

circuits = {}

for name, apply_gate in {
    "x": lambda qc: qc.x(0),
    "h": lambda qc: qc.h(0),
    "s_after_h": lambda qc: (qc.h(0), qc.s(0)),
    "ry_pi_over_2": lambda qc: qc.ry(np.pi / 2, 0),
}.items():
    qc = QuantumCircuit(1, name=name)
    apply_gate(qc)
    circuits[name] = qc

for name, qc in circuits.items():
    state = Statevector.from_instruction(qc)
    print(name, state.data, state.probabilities())
```

람다 표현이 낯설면 각 회로를 별도로 작성해도 됩니다. 중요한 것은 실행 전에 각 진폭을 예상하는 것입니다.

## 상대위상 관찰 실험

다음 두 회로는 중간 상태의 계산기저 확률이 같지만 마지막 결과가 다릅니다.

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

plus_path = QuantumCircuit(1)
plus_path.h(0)
plus_path.h(0)

minus_path = QuantumCircuit(1)
minus_path.h(0)
minus_path.z(0)
minus_path.h(0)

print(Statevector.from_instruction(plus_path).probabilities_dict())
print(Statevector.from_instruction(minus_path).probabilities_dict())
```

첫 회로는 $|0\rangle$, 둘째는 $|1\rangle$입니다. Z가 중간 확률을 바꾸지 않아도 간섭 결과를 바꿉니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. 상대위상과 전역위상을 구별하지 못하거나 행렬 곱의 적용 순서를 반대로 읽으면 코드 결과를 잘못 예측합니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
