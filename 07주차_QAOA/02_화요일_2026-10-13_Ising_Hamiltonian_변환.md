# 7주차 화요일 - Ising Hamiltonian 변환

## 목표

- binary variable을 Pauli Z operator로 치환합니다.
- QUBO 선형항·이차항을 I, Z, ZZ 항으로 변환합니다.
- constant offset과 최적 bitstring 관계를 설명합니다.
- classical objective와 operator eigenvalue를 전수 비교합니다.

## binary-to-spin mapping

계산기저에서

$$Z|0\rangle=+|0\rangle,qquad Z|1\rangle=-|1\rangle.$$

따라서 bit $x_i\in\{0,1\}$는

$$
x_i\mapsto\frac{I-Z_i}{2}
$$

로 대응합니다.

- bit 0: Z eigenvalue +1 → $(1-1)/2=0$
- bit 1: Z eigenvalue -1 → $(1-(-1))/2=1$

## 이차항

$$
x_ix_j
\mapsto
\frac{(I-Z_i)(I-Z_j)}4
=\frac14(I-Z_i-Z_j+Z_iZ_j).
$$

따라서 모든 QUBO는 constant, single-Z, ZZ 항의 합으로 바뀝니다.

## MaxCut Hamiltonian

한 edge의 cut value는

$$
x_i+x_j-2x_ix_j
=\frac12(I-Z_iZ_j).
$$

cut value operator는

$$
H_C=\frac12\sum_{(i,j)}w_{ij}(I-Z_iZ_j).
$$

최대화할 때 Estimator cost를 최소화하려면 $-H_C$를 사용하거나 optimizer의 목표를 반대로 설정합니다.

## SparsePauliOp

```python
from qiskit.quantum_info import SparsePauliOp

cut_operator = SparsePauliOp.from_list([
    ("III", 1.5),
    ("IZZ", -0.5),
    ("ZZI", -0.5),
    ("ZIZ", -0.5),
]).simplify()

cost_operator = -cut_operator
```

Pauli label의 qubit index 방향을 반드시 검증합니다. 위 label이 edge 목록과 일치하는지는 q0만 1인 basis state expectation으로 확인합니다.

## 전수 검증

```python
from qiskit.quantum_info import Statevector

for index in range(8):
    label = format(index, "03b")
    state = Statevector.from_label(label)
    quantum_value = float(state.expectation_value(cut_operator).real)
    print(label, quantum_value)
```

classical `cut_value`와 label convention을 맞춰 모든 8개 값이 일치하는지 확인합니다. 하나라도 다르면 sign, qubit order, constant offset을 점검합니다.

## offset

모든 상태에 같은 constant를 더하면 argmin·argmax는 바뀌지 않지만 reported energy는 바뀝니다. QUBO solver와 Hamiltonian 결과를 비교할 때 offset을 복원해야 합니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. x와 spin 매핑 부호, Pauli 문자열 순서, 최대화 문제의 부호를 섞으면 최저 에너지 상태가 원하는 최적해의 반대가 됩니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미
