## QAOA 상태

표준 QAOA는 균등중첩 $|+\rangle^{\otimes n}$에서 시작해 cost와 mixer unitary를 번갈아 적용합니다.

$$
|\boldsymbol\gamma,\boldsymbol\beta\rangle
=\prod_{k=1}^{p}
e^{-i\beta_kH_M}
e^{-i\gamma_kH_C}
|+\rangle^{\otimes n}.
$$

대표 mixer는

$$H_M=\sum_iX_i.$$

cost unitary가 objective의 phase를 encode하고 mixer가 basis 상태 사이를 이동하게 합니다. QAOA는 최적해를 매번 확정적으로 내는 보장이 있는 단순 회로가 아닙니다.

## QAOAAnsatz

```python
from qiskit.circuit.library import QAOAAnsatz

p = 1
ansatz = QAOAAnsatz(cost_operator, reps=p)

print(ansatz.parameters)
print(ansatz.decompose().draw("text"))
```

parameter 객체의 표시 순서를 출력하고 optimizer vector와 mapping을 기록합니다. `beta가 먼저일 것이다`처럼 추측하지 않습니다.

## 비용함수

```python
import numpy as np
from qiskit.primitives import StatevectorEstimator

estimator = StatevectorEstimator()

def cost_function(parameters: np.ndarray) -> float:
    job = estimator.run([
        (ansatz, cost_operator, [parameters])
    ])
    pub_result = job.result()[0]
    value = np.asarray(pub_result.data.evs).reshape(-1)[0]
    return float(np.real(value))
```

현재 버전의 parameter value shape에 맞는지 작은 vector 한 개로 먼저 확인합니다.

## sign 검증

cost_operator가 `-cut_operator`이면 최소 energy가 maximum cut에 대응합니다. 최적 parameter에서 보고한 energy에 minus·offset을 적용해 원래 cut value로 환산합니다.

## landscape 탐색

$p=1$이면 beta·gamma 두 parameter가 있으므로 coarse grid로 cost landscape를 그릴 수 있습니다. optimizer 전에 grid를 보면 주기성·local minima·sign error를 찾는 데 도움이 됩니다.

```python
betas = np.linspace(0, np.pi, 21)
gammas = np.linspace(0, 2 * np.pi, 41)
```

QAOA parameter periodicity는 Hamiltonian spectrum과 convention에 따라 달라질 수 있으므로 범위를 이유 없이 일반화하지 않습니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. QAOAAnsatz의 parameter 표시 순서를 beta-gamma라고 추측하거나 최대화 비용과 최소화 energy 부호를 혼동하면 optimizer 목표가 뒤집힙니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
