# 8주차 - 최종 프로젝트와 종합 복습

## 주간 목표

앞선 7주의 개념과 코드를 하나의 재현 가능한 프로젝트로 통합합니다. 최종 산출물은 `실행되는 노트북`을 넘어, 문제 정의·수학적 변환·고전 기준선·quantum workflow·검증·한계가 모두 설명된 학습 포트폴리오입니다.

## 일정

| 요일 | 주제 | 결과물 |
|---|---|---|
| 월 | 프로젝트 설계 | 요구사항·가정·테스트 계획 |
| 화 | 프로젝트 구현 | end-to-end 로컬 workflow |
| 수 | 검증과 개선 | unit tests·transpile·noise 분석 |
| 목 | 종합 복습·모의 문제 | 취약 개념 지도와 오답 노트 |
| 금 | 최종 평가·다음 로드맵 | 발표·평가표·90일 계획 |

## 완료 정의

- 다른 사람이 환경과 순서를 이해하고 재현할 수 있습니다.
- classical baseline과 quantum result를 같은 objective로 비교합니다.
- endian·sign·offset·parameter order를 테스트로 고정합니다.
- 실패한 시도와 한계를 숨기지 않습니다.
- 실제 QPU를 쓰지 않아도 프로젝트는 완결됩니다.
