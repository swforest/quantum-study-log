## 핵심 답안

<details><summary>1~5번</summary>

1. X=0, Y=1, Z=0.
2. $|+\rangle$에는 coherence가 있고 H 기저에서 확정적 +이지만 $I/2$는 모든 기저에서 최대 혼합입니다.
3. 유니터리 $U^\dagger U=I$는 가역 상태 변화, 에르미트 $A^\dagger=A$는 관측가능량과 실수 고유값.
4. $ad-bc=0$.
5. 전체 얽힘 상관을 포함한 state는 순수이나 상대 subsystem을 trace out하면 지역적으로 최대 혼합이 됩니다.

</details>

<details><summary>6~10번</summary>

7. 순수 상태, 유니터리, 샷 표본, 기대값 순서.
8. $HZH=X$이므로 $|1\rangle$.
9. 상태 분석·재사용·inverse·Estimator 사용을 어렵게 하므로 측정을 호출자가 선택하게 합니다.
10. `Statevector.from_instruction(qc)`.

</details>

<details><summary>11~16번</summary>

11. 논리 회로는 추상 gate·logical qubit, ISA는 특정 backend target·physical layout에 맞춘 회로.
12. metric 충돌, stochastic routing, compile 시간, 더 많은 2Q gate 가능성.
13. 지원 instruction, qargs/connectivity, error·duration properties.
14. logical observable을 실제 physical qubit mapping과 일치시키기 위해서입니다.
15. Sampler는 circuit·parameter values·shots, Estimator는 circuit·observables·parameter values·precision.
16. 독립 단건, 반복 sequential variational, 독립 다건 throughput.

</details>

<details><summary>17~20번</summary>

17. $x_i=(I-Z_i)/2$; Z eigenvalue +1/-1이 0/1로 대응.
18. Hamiltonian 부호를 반대로 하거나 optimizer objective를 negative expectation으로 정의.
19. local convergence·budget 종료만 의미할 수 있고 nonconvex landscape에 여러 minimum이 있습니다.
20. model·sign·offset 검증, optimum 기준, approximation quality 평가.

</details>

### 수학·논리 전개

종합 문제는 상태 표현에서 회로 변환, ISA 변환, 실행 도구, 결과 구조, 물리적 해석으로 이어지는 연결을 검사합니다. 어느 한 표현에서 다음 표현으로 번역하지 못하면 그 연결이 복습 우선순위입니다.

이 문장을 그대로 암기하지 말고 다음 순서로 다시 전개합니다.

1. 출발하는 상태, 데이터, 변수 또는 가정을 먼저 씁니다.

2. 적용되는 게이트, 행렬, 치환, API 변환을 한 단계씩 분리합니다.

3. 단계마다 보존되어야 하는 정규화, 차원, type, shape, mapping을 확인합니다.

4. 마지막 식이나 객체가 오늘 중심 질문에 어떤 답을 주는지 한 문장으로 연결합니다.

5. 부호, 순서, 인덱스 가운데 하나를 바꾸었을 때 결과가 어떻게 달라지는지 반례를 만듭니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. 답안을 읽고 이해된 느낌만 확인하거나 API 이름 암기에만 집중하면 새 오류나 변형 문제에서 지식을 꺼내지 못합니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
