## 세 기준선

1. 정확한 이론 분포: Statevector probability
2. 이상적 샷 분포: sampling variation만 존재
3. noisy 샷 분포: sampling variation + 모델 noise

이 세 가지를 한 그래프에 표시해야 noise 효과와 샷 변동을 혼동하지 않습니다.

## 분포 정규화

```python
def normalize_counts(counts: dict[str, int]) -> dict[str, float]:
    total = sum(counts.values())
    if total == 0:
        raise ValueError("Counts are empty")
    return {key: value / total for key, value in counts.items()}
```

## Total variation distance

두 분포 $p,q$의 TVD는

$$
D_{TV}(p,q)=\frac12\sum_x|p(x)-q(x)|.
$$

```python
def total_variation_distance(p, q):
    keys = set(p) | set(q)
    return 0.5 * sum(abs(p.get(k, 0.0) - q.get(k, 0.0)) for k in keys)
```

0이면 동일, 최대 1입니다. 이 값 하나만으로 오류 원인을 알 수는 없습니다.

## 완화 용어

- error suppression: 더 좋은 layout, dynamical decoupling, pulse/native gate 선택 등 오류 발생을 줄임
- error mitigation: 여러 noisy 결과를 후처리해 ideal observable을 더 잘 추정
- quantum error correction: 논리 qubit과 syndrome을 사용해 오류를 탐지·교정하는 fault-tolerant 방향

mitigation은 일반적으로 arbitrary state를 완벽 복구하지 않으며 비용·분산 증가·가정이 있습니다.

### 실험 질문

### 실행 전에 적을 내용

1. 입력 상태 또는 입력 데이터의 크기와 순서를 적습니다.

2. 회로나 수식이 적용되는 순서를 한 단계씩 번호로 씁니다.

3. 정확히 예측할 수 있는 출력과 유한 샷 때문에 흔들릴 출력을 구분합니다.

4. 성공을 판정할 수치 또는 구조적 조건을 하나 정합니다.

5. 실패했을 때 가장 먼저 출력할 type, shape, mapping, version을 적습니다.

오늘 가장 가능성 높은 실패는 다음과 같습니다. 샷 수가 다른 raw counts를 직접 빼거나 한 번의 seed 결과만으로 노이즈 개선을 주장하면 통계적 변동을 효과로 오해합니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
