# 1주차 - 양자 개념 복구

## 주간 목표

첫 주는 Qiskit 문법을 많이 외우는 주가 아닙니다. 앞으로 등장할 회로와 API를 이해하기 위해 필요한 수학적 언어와 양자역학의 최소 공리를 복구합니다. 예전에 배웠던 용어를 알아보는 수준이 아니라, 다음 질문에 자료 없이 답할 수 있는 것이 목표입니다.

1. 큐비트 상태는 왜 두 개의 복소수로 표현하는가?
2. 확률진폭과 측정 확률은 어떻게 다른가?
3. 모든 행렬이 양자 게이트가 될 수 없는 이유는 무엇인가?
4. 텐서곱은 두 큐비트의 상태 공간을 어떻게 만드는가?
5. Bell 상태는 왜 두 독립 큐비트의 곱으로 쓸 수 없는가?
6. 측정은 상태를 읽는 행위이면서 왜 상태를 변화시키는가?

## 첫 주 운영 원칙

- 계산기는 마지막 검산에만 사용합니다.
- 기호가 기억나지 않으면 의미를 말로 설명한 뒤 기호를 다시 연결합니다.
- 정답을 보기 전 항상 결과의 형태를 먼저 예측합니다.
- 복소수 계산 실수와 양자 개념 오류를 구분합니다.
- 코드 출력은 수학적 계산을 대신하는 답이 아니라 검증 도구입니다.
- 한 문제에서 10분 이상 막히면 힌트를 받고 사고 과정을 기록합니다.

## 주간 진단 기준

금요일이 끝났을 때 아래를 자료 없이 수행합니다.

- [ ] $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$의 각 항을 설명한다.
- [ ] 주어진 두 복소수 진폭으로 상태가 정규화되었는지 검사한다.
- [ ] X와 H 게이트를 상태벡터에 곱한다.
- [ ] 두 1큐비트 상태의 텐서곱을 계산한다.
- [ ] Bell 상태의 측정 분포를 설명한다.
- [ ] Bell 상태가 분리 불가능함을 계수 비교로 보인다.
- [ ] 유한 샷 결과와 이론 확률의 차이를 설명한다.

5개 이상이면 2주차로 진행합니다. 3~4개이면 2주차를 진행하되 매일 첫 15분에 취약 개념을 반복합니다. 2개 이하이면 첫 주 문서를 60분짜리 압축 복습으로 한 번 더 진행합니다.
