# 3주차 - 양자정보와 상태 표현

## 주간 질문

같은 양자 정보를 상태벡터, 연산자, Pauli 관측가능량, 밀도행렬, 그림으로 표현할 때 각 표현은 무엇을 보여주고 무엇을 숨기는가?

## 일정과 결과물

| 요일 | 주제 | 결과물 |
|---|---|---|
| 월 | Statevector | 상태 준비·변환·측정 확률 분석 |
| 화 | Operator·전역위상 | 회로와 행렬의 동등성 검사 |
| 수 | Pauli·기대값 | 관측가능량 기대값 계산표 |
| 목 | DensityMatrix·Fidelity | 순수·혼합 상태 비교 |
| 금 | 상태 시각화·복습 | 표현 선택 가이드와 주간 노트북 |

## 완료 기준

- 상태벡터와 측정 표본을 혼동하지 않습니다.
- 회로 합성과 행렬 곱의 순서를 설명합니다.
- 기대값이 확률 그 자체가 아님을 설명합니다.
- 순수 중첩과 고전적 혼합을 밀도행렬로 구분합니다.
- 시각화마다 손실되는 정보를 지적합니다.
