## 기대값

관측가능량 $A$의 상태 $|\psi\rangle$에 대한 기대값은

$$
\langle A\rangle_\psi
=\langle\psi|A|\psi\rangle.
$$

기대값은 동일한 상태 준비와 측정을 많이 반복했을 때 관측값의 평균입니다. 한 번의 측정 결과와 다릅니다.

Z의 고유값은 +1과 -1입니다. 상태 $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$이면

$$
\langle Z\rangle=|\alpha|^2-|\beta|^2.
$$

따라서 $P(0)=(1+\langle Z\rangle)/2$입니다.

## 손계산 예

- $\langle0|Z|0\rangle=1$
- $\langle1|Z|1\rangle=-1$
- $\langle+|Z|+\rangle=0$
- $\langle+|X|+\rangle=1$

같은 상태도 어떤 관측가능량을 측정하는지에 따라 기대값이 달라집니다.

## Qiskit quantum_info

```python
from qiskit.quantum_info import Statevector, SparsePauliOp

state = Statevector.from_label("+")
x = SparsePauliOp.from_list([("X", 1.0)])
z = SparsePauliOp.from_list([("Z", 1.0)])

print(state.expectation_value(x))
print(state.expectation_value(z))
```

## 다중 Pauli

```python
hamiltonian = SparsePauliOp.from_list([
    ("ZI", 0.5),
    ("IZ", 0.5),
    ("XX", 1.2),
])
```

Pauli label과 qubit index의 순서를 비대칭 상태로 확인합니다. `ZI`를 눈으로 보고 q0에 Z라고 단정하지 않습니다.

선형성 때문에

$$
\langle aA+bB\rangle
=a\langle A\rangle+b\langle B\rangle.
$$

이 성질이 Hamiltonian을 Pauli 항의 합으로 나누어 측정하는 기반입니다.

## 분산

기대값만으로 결과의 퍼짐을 알 수 없습니다.

$$
\operatorname{Var}(A)=\langle A^2\rangle-\langle A\rangle^2.
$$

예를 들어 $|+\rangle$에서 Z 기대값은 0이지만 결과가 항상 0이라는 뜻이 아니라 +1과 -1이 절반씩 나타납니다. 분산은 1입니다.

## 과제

1. $|r\rangle=(|0\rangle+i|1\rangle)/\sqrt2$의 X, Y, Z 기대값을 구합니다.
2. Bell $|\Phi^+\rangle$에서 $ZZ$, $XX$, $ZI$ 기대값을 예상합니다.
3. 세 Pauli 항 Hamiltonian을 만들고 `Statevector.expectation_value`로 검산합니다.
4. 기대값 0을 `관측 결과 0`이라고 해석하면 안 되는 이유를 예로 설명합니다.

## 핵심 답

`|r>`의 기대값은 X=0, Y=1, Z=0입니다. $\Phi^+$에서는 ZZ=1, XX=1, 한쪽만 Z인 기대값은 0입니다.

### 수학·논리 전개

기대값은 psi dagger A psi이고 분산은 기대값 A squared에서 기대값 A의 제곱을 뺀 값입니다. Pauli 관측량은 A squared=I이므로 분산은 1-기대값의 제곱으로 단순화됩니다.

이 문장을 그대로 암기하지 말고 다음 순서로 다시 전개합니다.

3. 단계마다 보존되어야 하는 정규화, 차원, type, shape, mapping을 확인합니다.

5. 부호, 순서, 인덱스 가운데 하나를 바꾸었을 때 결과가 어떻게 달라지는지 반례를 만듭니다.

### 손으로 따라가는 예제

plus 상태에서 X 기대값은 plus 1이고 분산은 0입니다. 같은 상태에서 Z 기대값은 0이지만 Z 측정 결과 plus 1과 minus 1이 반씩 나와 분산은 1이므로 기대값 0을 결과 0으로 오해하면 안 됩니다.

오늘 가장 가능성 높은 실패는 다음과 같습니다. Pauli 문자열의 왼쪽 문자를 q0 연산으로 읽거나 기대값 0을 항상 무작위 상태라고 해석하면 관측량 의미를 놓칩니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
