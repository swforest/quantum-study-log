# 3주차 목요일 - DensityMatrix와 Fidelity

## 목표

- 순수 상태 밀도행렬 $\rho=|\psi\rangle\langle\psi|$를 계산합니다.
- 순수 중첩과 고전적 혼합을 구분합니다.
- trace, purity, partial trace의 의미를 설명합니다.
- state fidelity를 상태 유사도 지표로 올바르게 사용합니다.

## 왜 밀도행렬이 필요한가

다음 두 준비는 계산기저 확률이 같습니다.

1. 순수 상태 $|+\rangle$
2. 절반은 $|0\rangle$, 절반은 $|1\rangle$로 준비한 혼합

하지만 H 기저에서 측정하면 다릅니다. 순수 $|+\rangle$은 확정적으로 +이고 혼합은 여전히 무작위입니다.

순수 상태:

$$
\rho_+=|+\rangle\langle+|
=\frac12\begin{bmatrix}1&1\\1&1\end{bmatrix}.
$$

혼합 상태:

$$
\rho_{mix}=\frac12|0\rangle\langle0|
+\frac12|1\rangle\langle1|
=\frac12\begin{bmatrix}1&0\\0&1\end{bmatrix}.
$$

대각 원소는 계산기저 population, 비대각 원소는 이 기저에서 coherence 정보를 담습니다.

## 밀도행렬 조건

- Hermitian: $\rho^\dagger=\rho$
- positive semidefinite
- trace 1: $\operatorname{Tr}\rho=1$

순수도:

$$
\gamma=\operatorname{Tr}(\rho^2).
$$

순수 상태는 1, 최대 혼합 1큐비트는 1/2입니다.

## Qiskit

```python
from qiskit.quantum_info import DensityMatrix, Statevector

plus_dm = DensityMatrix(Statevector.from_label("+"))
mixed_dm = 0.5 * DensityMatrix.from_label("0") + \
           0.5 * DensityMatrix.from_label("1")

print(plus_dm.data)
print(mixed_dm.data)
print("plus purity:", plus_dm.purity())
print("mixed purity:", mixed_dm.purity())
```

## 부분 추적과 얽힘

전체 Bell 상태는 순수하지만 한 큐비트만 보면 최대 혼합입니다.

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import DensityMatrix, partial_trace

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

rho_ab = DensityMatrix.from_instruction(qc)
rho_a = partial_trace(rho_ab, [1])

print(rho_ab.purity())
print(rho_a.data)
print(rho_a.purity())
```

부분계가 혼합이라는 사실은 전체 상태가 반드시 혼합이라는 뜻이 아닙니다. 전체 순수 얽힘 상태에서 환경 또는 상대 부분계를 버리면 부분 상태가 혼합이 될 수 있습니다.

## Fidelity

fidelity는 두 상태의 유사도를 0~1 범위로 나타냅니다. 순수 상태끼리는 흔히

$$F(|\psi\rangle,|\phi\rangle)=|\langle\psi|\phi\rangle|^2$$

입니다. 라이브러리 정의가 제곱 fidelity인지 root fidelity인지 문서를 확인합니다.

```python
from qiskit.quantum_info import state_fidelity

print(state_fidelity(
    Statevector.from_label("+"),
    Statevector.from_label("-"),
))
```

직교 상태이므로 0입니다. 전역위상만 다른 상태는 1입니다.

## 과제

2. $p|0\rangle\langle0|+(1-p)|1\rangle\langle1|$의 purity를 $p$로 표현합니다.
3. Bell 상태의 두 부분계 reduced density matrix를 구합니다.
4. $|0\rangle$, $|+\rangle$의 fidelity를 계산합니다.

- 틀린 접근: 대상 개념의 이름이나 코드 호출만 기억하면 의미도 안다고 생각합니다. 대상은 상태 거리와 진단입니다.
- 교정 근거: fidelity 하나는 가까움의 크기만 주므로 오류 종류와 관측량별 영향은 추가 지표로 분석해야 합니다.
- 확인 질문: 대상 개념 상태 거리와 진단에서 입력 조건 하나가 바뀌면 어떤 출력이 달라집니까?
- 최소 반례: 대상 개념 상태 거리와 진단에서 조건 하나를 깨뜨린 작은 예를 만듭니다.
- 복구 행동: 본문의 상태 거리와 진단 예제를 가장 작은 크기로 줄여 손계산과 다시 비교합니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. 밀도행렬의 대각 원소만 보거나 fidelity를 단순한 벡터 내적으로만 계산하면 혼합상태와 부분계 상태를 잘못 해석합니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
