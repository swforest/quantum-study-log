## Statevector의 의미

`Statevector`는 순수 상태의 복소수 진폭을 보유합니다. 샷 수나 count가 아니라 이상적인 상태 자체입니다.

```python
import numpy as np
from qiskit.quantum_info import Statevector

zero = Statevector.from_label("0")
plus = Statevector.from_label("+")
custom = Statevector([1 / np.sqrt(3), np.sqrt(2 / 3)])

for state in [zero, plus, custom]:
    print(state.data)
    print(state.probabilities_dict())
```

label은 `0`, `1`, `+`, `-`, `r`, `l` 등을 지원합니다. `r`, `l`의 위상 관례는 API 문서를 확인하고 손계산과 비교합니다.

## 회로에서 생성

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

bell = Statevector.from_instruction(qc)
print(bell.draw("text"))
```

measurement·reset 같은 비단일 instruction이 포함되면 단순 순수 상태 진화로 다룰 수 없습니다. 상태 준비와 측정 회로를 분리합니다.

## evolve

```python
from qiskit.circuit.library import HGate, ZGate

state = Statevector.from_label("0")
state = state.evolve(HGate())
state = state.evolve(ZGate())

print(state.draw("text"))
```

`evolve`는 입력 상태가 연산자를 거친 결과를 반환합니다. 원본을 자동 변경한다고 가정하지 말고 반환값을 받습니다.

## 부분 subsystem과 qargs

다중 큐비트 상태에서 특정 qubit에 연산을 적용할 때 `qargs` 순서를 명시할 수 있습니다.

```python
from qiskit.quantum_info import Operator

state = Statevector.from_label("00")
x = Operator([[0, 1], [1, 0]])
changed = state.evolve(x, qargs=[0])
print(changed.probabilities_dict())
```

출력을 예측한 뒤 q0가 Qiskit state label의 어느 쪽에 보이는지 확인합니다.

## 상태의 동등성

$$|\psi\rangle$$과 $e^{i\gamma}|\psi\rangle$은 같은 물리 상태입니다.

```python
a = Statevector([1, 0])
b = Statevector([1j, 0])

print(a == b)
print(a.equiv(b))
```

직접 배열 동일성은 거짓이지만 전역위상을 고려한 동등성은 참입니다.

## Statevector의 한계

- 순수 상태만 직접 표현합니다.
- 환경과 얽힌 부분계의 혼합 상태를 단일 statevector로 표현할 수 없습니다.
- 실제 장치 노이즈의 일반적인 ensemble을 충분히 표현하지 못합니다.
- 한 개 statevector를 안다고 해서 실험에서 한 번에 그 진폭을 읽을 수 있는 것은 아닙니다.

- 교정 근거: 벡터 원소가 문자 그대로 같지 않아도 공통 위상 인자만 다르면 모든 물리적 예측이 같습니다.
- 확인 질문: 대상 개념 equiv와 전역위상에서 입력 조건 하나가 바뀌면 어떤 출력이 달라집니까?
- 최소 반례: 대상 개념 equiv와 전역위상에서 조건 하나를 깨뜨린 작은 예를 만듭니다.
- 복구 행동: 본문의 equiv와 전역위상 예제를 가장 작은 크기로 줄여 손계산과 다시 비교합니다.

### 오개념 8: 상태벡터의 한계

- 틀린 접근: 대상 개념의 이름이나 코드 호출만 기억하면 의미도 안다고 생각합니다. 대상은 상태벡터의 한계입니다.
- 교정 근거: 혼합상태, 결과를 버린 측정, 일반 노이즈 채널은 하나의 순수 상태벡터만으로 표현할 수 없습니다.
- 확인 질문: 대상 개념 상태벡터의 한계에서 입력 조건 하나가 바뀌면 어떤 출력이 달라집니까?
- 최소 반례: 대상 개념 상태벡터의 한계에서 조건 하나를 깨뜨린 작은 예를 만듭니다.

## 7. 실패 진단 절차

오늘 가장 가능성 높은 실패는 다음과 같습니다. 배열 인덱스를 q0부터 왼쪽으로 읽거나 측정이 포함된 회로를 그대로 순수 상태 계산에 넣으면 의미 또는 API 단계에서 문제가 생깁니다.

### 1단계: 환경

- Python, Qiskit, 선택 패키지 버전을 출력합니다.
- 노트북 kernel과 패키지를 설치한 interpreter가 같은지 확인합니다.
- 구형 예제의 import와 현재 API를 이름만 바꾸지 말고 목적별로 매핑합니다.

### 2단계: 입력

- qubit 수, classical bit 수, parameter 수를 적습니다.
- 배열 shape와 axis 의미를 적습니다.
- bitstring과 Pauli 문자열의 변수 순서를 적습니다.

### 3단계: 변환

- 회로 instruction 순서와 compose 순서를 확인합니다.
- transpilation이 있다면 원본과 ISA 회로를 분리합니다.
- layout, register mapping, parameter binding을 출력합니다.

### 4단계: 출력

- result 객체를 추측하지 않고 type, 첫 PUB, data, key 순서로 내려갑니다.
- 정확값, 기대값, 샷 counts 가운데 지금 얻은 결과의 종류를 적습니다.
- 값이 아니라 shape부터 예측과 비교합니다.

### 5단계: 의미

- 코드가 성공했다는 사실만으로 물리적·수학적 정답이라고 결론 내리지 않습니다.
- 독립적인 손계산 또는 brute-force 기준선과 비교합니다.
- 남은 차이를 모델 오류, 구현 오류, 통계 변동으로 분류합니다.
